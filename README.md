# Sentiment Analysis of Trader Behavior

## Setup

<details>
<summary>Click to view setup requirements</summary>

### Requirements
- Python 3.8 or higher
- Jupyter Notebook or JupyterLab

### Python Libraries
Make sure the following libraries are installed in your environment:
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- jupyter

</details>

---

## How to Run

<details>
<summary>Run the analysis notebook</summary>

1. Clone this repository and navigate to the project directory.
2. Ensure the required Python environment and libraries are available.
3. Launch Jupyter Notebook or JupyterLab.
4. Open the main notebook file.
5. Run the notebook cells sequentially from top to bottom to reproduce the analysis.

</details>
